# Why this desk uses commands

A facility coordinator needs to know which instrument is free, whose training is current and which service holds affect the week. Those answers come from booking and evidence records. This base keeps that internal desk in a database and produces read-only reports.

A graphical calendar offers drag-and-drop changes and immediate shared visibility. A researcher portal offers independent booking, authenticated approvals and mobile access. Kiosks and hardware interlocks connect physical use to records. This base provides none of those; it runs for trusted operators and can work locally without an internet connection after installation. Agent services can still need internet access.

Choose this base for a coordinator-led facility where requests can be entered through the CLI.
